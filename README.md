# its.muhammadalamin — Personal Identity Website

A simple black-and-gold personal website prepared for GitHub Pages.

## Before publishing
1. Replace `assets/profile.svg` with your own profile photo named `profile.jpg` (or update the image path in `index.html`).
2. In `index.html`, replace the `href="#"` values for Facebook, Instagram, WhatsApp, and Telegram with your real profile links.
3. The email button is set to `its.muhammadalamin@gmail.com`; change it if needed.

## Publish with GitHub Pages
1. Sign in at https://github.com
2. Create a **public** repository named exactly `itsmuhammadalamin.github.io` (if available).
3. Upload `index.html` and the `assets` folder to the repository root.
4. Open **Settings → Pages**. Select **Deploy from a branch**, choose **main** and **/(root)**, then Save.
5. Wait a few minutes, then open `https://itsmuhammadalamin.github.io`.

If that repository name is already taken, choose another repository name and enable Pages in Settings; the URL will then include the repository name.
